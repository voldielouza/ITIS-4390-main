# StagePass

## Run locally

1. Open this folder in VS Code.
2. Make sure the Live Server extension is installed.
3. Open `index.html`.
4. Click **Go Live**.

## Pages

- `index.html` - Home page
- `checkout.html` - Purchase / checkout page
- `ticket.html` - Purchased ticket viewer

The project uses `styles.css`, `script.js`, and the `assets` folder for shared styling, behavior, and images.
